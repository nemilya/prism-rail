# Переводы: что где лежит и как добавить язык

По образцу `nemilya/scantunnel` (`docs/i18n.md`): каждая локаль — отдельные статические страницы со своим
URL, `<html lang>`, canonical и hreflang на все языки; основной язык — английский, в корне сайта.

## Языки сейчас

| Язык | Симулятор | «О проекте» | Ролик `refraction` |
|---|---|---|---|
| en | `/` (основной) | `/about/` | тексты ✓, озвучка — `make voice FILM=refraction LANGS=en` |
| ru | `/ru/` | `/ru/about/` | ✓ (озвучен) |

## Где тексты

| Что | Файл | После правки |
|---|---|---|
| Языки, адрес сайта (canonical, hreflang, sitemap) | `site/site.mjs` | `make test`, `make dist` |
| «О проекте»: тексты, `<title>`, description, og; описание симулятора (`sim.description`) | `site/i18n/<code>.mjs` (ключи совпадают — тест) | `make test`, `make dist` |
| «О проекте»: разметка | `site/about.html` (`{{ключ}}`) | — |
| Главы ролика и время «в ролике с …» | из ролика: `chapters` в `video/films/refraction/i18n.js`, время — по озвучке языка | сами пересчитаются |
| Интерфейс симулятора | `sim/index.html`: разметка и `t('…')` в коде — английский, перевод — словарь `RU` в скрипте языка | `make test` (ловит непереведённое и лишнее) |
| Автовыбор языка | `site/lang.js` → `TZ` (пояса IANA, тест) | `make test` |
| Плеер ролика: кнопки, подсказки | `UI` в `video/player.js` | — |
| Ролик: подписи, реплики, плашка «тестовый ролик» (`disclaimer`), единицы (`nm`, `dec`) | `video/films/<id>/i18n.js` (ключи и длины списков как у `ru` — тест) | `make voice`, `make video`, `make web` |
| Ролик: голоса и манера | `video/voice.config.json` → `voice.<code>`, `instructions.<code>` | `make voice` |

## Как выбирается язык

`site/lang.js` — блокирующий скрипт в `<head>` каждой страницы сайта:

1. явный выбор — `prism-lang` в `localStorage` (клик по EN / RU в симуляторе или на «О проекте», «Switch» или × в плашке);
2. основной язык браузера, если это не основная локаль (`ru-RU` → ru);
3. страна по часовому поясу: Россия, Беларусь, Казахстан → ru;
4. иначе en.

Уводим (`location.replace`) только с основной страницы (`/`, `/about/`) и только человека, пришедшего снаружи;
боты и переходы внутри сайта остаются. С `/ru/` не уводим; на `/ru/about/` по тому же выбору — плашка
«This page is also available in English». Автовыбор не запоминается.

Плеер `video/` выбирает язык ролика сам: `?lang` → кнопка EN / RU (`prism-video-lang`) → язык браузера → en.
Симулятор прямо из репозитория (`sim/`, без обёртки сайта) — `?lang=ru`.

## Новый язык — чек-лист

1. `site/i18n/<code>.mjs` — копия `en.mjs`, перевести всё; строка в `locales` в `site/site.mjs`.
2. `sim/index.html` — сейчас симулятор знает один словарь `RU`: добавить свой словарь, `LANGS`
   и выбор словаря в скрипте языка; тест в `site/tests/site.test.mjs` — по образцу RU.
3. `site/lang.js` — страны языка в `TZ` (без поясов, общих с другими языками); тест — `site/tests/`.
4. Ролик: блок `<code>` в `video/films/<id>/i18n.js` (копия `en`), голос и манера в `video/voice.config.json`,
   подписи плеера — `UI` в `video/player.js`. Шрифты ролика (`video/fonts/`) — латиница и кириллица.
5. `make test`, `make stills FILM=refraction LANGS=<code> T=…` — длинные подписи на чертежах,
   `make play` — страницы `/<code>/` и `/<code>/about/`.

## Выпуск ролика на языке

```bash
make voice FILM=refraction LANGS=en    # озвучка (OPENROUTER_API_KEY, платно) → video/films/refraction/voice/en.*
make video FILM=refraction LANGS=en    # MP4 (~1 ч без видеокарты)
make web FILM=refraction LANGS=en      # out/refraction/web/refraction-en.{mp4,jpg,vtt}
make dist                              # media/refraction-en.* → «О проекте» на английском играет MP4
```

Пока озвучки языка нет, таймлайн ролика и главы на «О проекте» считаются по оценке длины реплик;
после `make voice` всё пересчитывается само. Озвучку (`voice/<code>.{json,m4a,vtt}`) — коммитить.

**Плашка «тестовый ролик»** (`disclaimer`) видна в первой сцене (слева вверху) и на финальной карточке, а
также под роликом на «О проекте» и в плеере. Её появление в кадре не меняет таймлайн, поэтому русская озвучка
остаётся годной — достаточно перерендерить ролик (`make video` / `make web`).
