# Prism Rail

Браузерный 3D-симулятор световой инсталляции: игрушечная тележка с двумя боковыми прожекторами едет по замкнутой трассе в тёмной комнате среди дихроичных стёкол. Свет отражается и проходит сквозь стёкла, рисуя цветные блики, а генеративная музыка следует за светом.

## Файлы

- `sim/index.html` — рабочий прототип одним файлом (Three.js r128 UMD + Tone.js 14.8 с jsdelivr). Эталон поведения и источник подобранных значений. `?embed` — режим съёмки для роликов: без интерфейса и своего цикла кадров, API `window.prism` (кадр — чистая функция состояния).
- `index.html` (корень) — переход в `sim/` с кодом сцены из `#hash`: стартовая страница — сам симулятор (сразу идёт, звук — от первого касания; ссылки «Ролик» и «О проекте» в нижней панели).
- `about/` — «О проекте»: ролик с главами, физика, кадры симулятора, вдохновение (DEVIATION). Веб-версия ролика — `../media/refraction-ru.{mp4,jpg}`: её кладёт в `dist/media/` сборка; без неё страница ведёт в живой плеер `video/`.
- `make dist` → `dist/` (не в git) — готовый сайт, копируется на хостинг как есть (`tools/dist.mjs`: `index.html`, `sim/`, `about/`, `media/` из `out/<id>/web/`, плеер `video/` без инструментов); `make preview` — локально, `make deploy` — rsync на `DEPLOY` из `local.mk`. Новый файл, нужный в браузере, — добавить в `files()` в `tools/dist.mjs`.
- `video/` — обучающие ролики по симулятору (конвейер из `nemilya/n-dacha`): сцены, чертежи, озвучка диалогом, рендер MP4 — `video/README.md`. Команды — `make help` из корня; MP4 и кадры — в `out/` (не в git).
- `docs/spec.md` — полная постановка задачи. Источник правды по требованиям, этапам и критериям приёмки. Схема архитектуры при экспорте выпала — список модулей продублирован ниже.

## Принятые решения

- Одна тележка, без поезда из вагонов.
- Только десктоп-браузер, мобильной версии нет.
- Трасса не редактируется руками: пользователь выбирает форму и seed.
- Экспорта видео нет, только PNG-снимки.
- Реализм правдоподобный, а не физически точный: трассировку заменяем дешёвыми приёмами.

## Целевая архитектура

Vite + TypeScript, актуальный Three.js, pmndrs/postprocessing, Tone.js.

- Строится один раз из seed: `Config/State`, `TrackGenerator`, `GlassScatter`, `Room`.
- Каждый кадр: `Train` → `LightRig` → `OpticsSolver` → рендер; `CameraDirector` отдельно.
- Рендер: `GlassMaterial`, `BeamVolumes`, `SpotDecals`, `PostFX`.
- `MusicEngine` получает от `OpticsSolver` события вспышек стёкол и суммарную яркость, от `Train` — скорость и стыки.
- `OpticsSolver` — чистая функция (позиции прожекторов + стёкла → блики, яркости, события), без зависимостей от Three-сцены, с unit-тестами.

## Что уже найдено в прототипе (переносить как есть)

**Единицы и масштаб.** 1 = 1 м. Комната 8 × 6 × 3. Колея 45 мм, тележка ~12 см, секции рельсов 0.3 м (стыки задают стук и микропокачивание).

**Детерминизм.** PRNG `mulberry32(hash(seed + '|' + shape))`. Код сцены: `shape.count.palette.attract*100.size*10.seed`, например `clover.300.spectrum.40.10.lumen-482`.

**Трассы.** `CatmullRomCurve3` (closed, centripetal), движение по длине дуги через `getPointAt`. Формы: oval, clover, wave, eight, random (звёздчатый многоугольник со сглаженными радиусами).

**Стёкла.** Dart throwing: вероятность `(0.1 + 0.9·exp(−d/σ)) · рощи`, где d — расстояние до трассы, рощи — сумма гауссиан. Коридор 8.5 см от оси трассы, минимум 7 см между стёклами. Форма — выпуклый осколок из 3–5 вершин, наклон ±5°. λ₀ из палитры: spectrum 440–660, ice 430–520, warm 560–660, mono 462–478 нм.

**Дихроика (одна модель в JS и GLSL).**
- `λpeak = λ0 · sqrt(1 − (sinθ / 1.6)²)`
- `spectral(w)` — три гауссианы (R 610/50 + 0.3·420/25, G 545/45, B 455/35).
- `C_r` = среднее spectral по λpeak и λpeak ± 30 нм, нормировка по максимуму; `C_t = 1 − 0.92·C_r`, нормировка по максимуму.
- `R(θ) = 0.35 + 0.45·(1 − cosθ)³`.
- Камера на стороне прожектора видит `C_r`, на противоположной — `C_t`.

**Рендер стёкол.** Все стёкла в одном `BufferGeometry` + `LineSegments` для граней, additive blending, без записи глубины. Данные по стёклам — Float `DataTexture` размером N × 4: строки 0–2 — пропускание (окклюзия) от каждого из трёх прожекторов, строка 3 — свечение + вспышка от ноты. Конус прожектора считается в фрагментном шейдере, поэтому пятно света ложится на стекло полосой.

**OpticsSolver (CPU, каждый кадр).** Кандидаты в конусе по горизонтальному углу с учётом углового размера стекла + вертикальное перекрытие с конусом; сортировка по расстоянию; окклюзия — перемножение `C_t` стёкол, стоящих раньше на том же луче. Топ-K (12 / 20 / 32 по качеству) дают отражённый и прошедший лучи; пересечение с плоскостями комнаты аналитическое. Отражённый луч проверяется на попадание в другое стекло (2D-отрезок + высота) → вторичное свечение и эхо-нота.

**Пятна и лучи.** Пятна — `InstancedMesh` плоскостей с процедурной маской осколка, длина `width / sin(grazing)`, не больше 1.7 м. Лучи в дыму — `InstancedMesh` конусов (основные + до 18 отражённых), additive, 3D-шум, затухание по длине.

**Пост.** Рендер в HalfFloat target → UnrealBloom → свой финальный пасс (ACES, гамма 2.2, хроматическая аберрация, виньетка, зерно). `renderer.toneMapping = NoToneMapping`.

**Музыка (Tone.js).**
- Дрон: PolySynth fatsawtooth → lowpass, аккорд раз в 8 тактов по ступеням [0, 3, 4, 2]; громкость и фильтр следуют суммарной яркости.
- Стекло: 8 FMSynth с Panner по кругу, квантование на 1/8, не больше 3 нот в слот; высота от λ₀ (синие выше), панорама по экранной позиции, эхо октавой выше на −9 дБ через 1/8.
- Пульс: MembraneSynth на каждом стыке рельсов. Воздух: pink noise → AutoFilter, громкость от дыма.
- Общий Reverb 5–10 с, PingPongDelay для стекла, Limiter на мастере.
- Темп = скорость / 0.3 · 60, в пределах 40–110. Гистерезис нот: включение > 0.35, выключение < 0.2.
- Лад: spectrum → пентатоника, ice → лидийский, warm → дорийский, mono → одна нота, пресет «Хаос» → целотонный. Тоника из seed.
- LFO 0.08 Гц «дышит» и в дроне, и в яркости лучей (±5%), грань стекла вспыхивает в момент атаки его ноты.

**Камеры.** Кино (4 шота по 11 с: проезд рядом, общий план, засада впереди, сверху), орбита, на борту, погоня. Клик по сцене переключает на орбиту.

## Известные ограничения прототипа

- Яркость, bloom и баланс цветов подобраны без визуальной проверки — сверять глазами.
- Нет raymarched-объёма, цветных теней, автокачества, уровня Ultra.
- «Поделиться» сделано кодом сцены, а не URL hash (ограничение артефакта claude.ai); в проекте можно вернуть hash.
- Снимок использует capability `downloads` артефакта claude.ai; в standalone кнопка скрыта — заменить на обычное скачивание.
- Логику прототипа проверяли прогоном в Node с мок-THREE, шейдеры — компиляцией в headless Chromium. В проекте завести нормальные тесты для генераторов и `OpticsSolver`.

## Как работать

- Общение на русском, код и идентификаторы на английском.
- Идти по этапам из `docs/spec.md`; каждый этап заканчивается рабочей версией.
- Значения по умолчанию брать из `sim/index.html`, если spec не говорит иначе.
- Прототип не ломать: он остаётся эталоном, пока новая версия не догонит его по картинке и звуку. Ролики снимают его через `?embed` — после правок симулятора `make test` и `make stills FILM=refraction T=…`.
- Ролики: сцены — чистые функции времени (без `Math.random`, `Date`, часов); облачная сессия — только `make test` и `make stills`, полный MP4 (~1 ч без видеокарты) и озвучку (стоит денег) — по просьбе пользователя.
